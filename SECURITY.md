# Security Policy

## Supported Versions

We actively provide security updates for the following versions of **localrag-kit**:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

The RitualDev team takes the security of our local-first software and our users' privacy seriously.

If you believe you have discovered a security vulnerability in **localrag-kit**, please **do not report it through a public GitHub issue**.

Instead, please report it via one of the following methods:

1. **GitHub Private Vulnerability Reporting**:
   - Navigate to the [Security Advisories](https://github.com/RitualDev-Lab/localrag-kit/security/advisories) tab and click **"Report a vulnerability"**.

2. **Direct Studio Email**:
   - Email: **[developer@ritualdev.com](mailto:developer@ritualdev.com)**
   - Subject: `[SECURITY] localrag-kit vulnerability report`
   - Include:
     - Description of the sensitivity or vulnerability
     - Steps to reproduce or proof-of-concept
     - Affected versions and hardware environments
     - Potential impact

---

## Response Timeline

- **Initial Acknowledgment**: Within 48 hours.
- **Triage & Reproduction**: Within 5 business days.
- **Fix & Public Disclosure**: Coordinated release with credit attribution in release notes.
